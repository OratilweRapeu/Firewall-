+++ Live tool +++

Paste. Diagnose.

How to capture the output (FortiGate and SonicWall) 
diagnose debug reset
diagnose debug flow filter addr SOURCE_IP
diagnose debug flow show function-name enable
diagnose debug flow trace start 20
diagnose debug enable
(generate the traffic, then copy the output)
diagnose debug disable
diagnose debug reset

SonicWall: run Packet Monitor, reproduce the traffic, and paste the dropped-packet lines that contain “Drop Code”. Drop code numbers change between firmware versions, so the tool matches on the description text.

+++ Coverage +++

What it catches today.

FortiGate
  • No matching policy, explicit deny, reverse path check
  • Replies with no session, local-in blocks, IPsec selectors
  • Allowed traffic that still fails
SonicWall
  • Policy drop, bounce on same link, Cache Add Cleanup
  • Reverse path check, flood protection

Early version. Anything it does not know says so instead of guessing.
